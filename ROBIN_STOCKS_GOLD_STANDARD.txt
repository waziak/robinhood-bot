📊 INTEGRATION IN ROBINHOOD BOT v2

File: bot.py (480 lines)

Authentication:
  def authenticate(self):
      rh.login(config.RH_USERNAME, config.RH_PASSWORD)
      # MFA handled automatically if enabled

Market Data (Indicators):
  def fetch_price_history(self, symbol: str):
      historicals = rh.get_historicals(symbol, interval='5minute', span='week')
      closes = [float(h['close_price']) for h in historicals]
      # Used by indicators.py (RSI, MACD, SMA)

Live Quotes (Exit Logic):
  def get_current_price(self, symbol: str):
      quote = rh.get_quotes(symbol)[0]
      return float(quote['last_trade_price'])
      # Used by manage_exits() for live exit checks

Buying Power (Risk Management):
  def check_buying_power(self, position_dollars: float):
      account = rh.get_account()
      buying_power = float(account['buying_power'])
      return position_dollars <= buying_power
      # Prevents insufficient funds errors

Portfolio Value (Risk Gate):
  def get_current_portfolio_value(self):
      account = rh.get_account()
      return float(account['portfolio_value'])
      # Used by portfolio_drawdown_check()

Order Execution (Fractional Shares):
  def place_buy_order(self, symbol: str, dollar_amount: float):
      quantity = dollar_amount / self.get_current_price(symbol)
      # quantity can be fractional: 0.3341, 0.5194, 1.0778, etc.
      if not config.PAPER_MODE:
          rh.order_buy_market(symbol, quantity)  # Robin Stocks handles fractional

❓ FAQ

Q: What if MFA code expires?
A: Robin Stocks auto-refreshes the session token. If truly expired,
   bot will prompt for new MFA code.

Q: Can I buy $5.23 worth of a stock?
A: Yes! Robin Stocks fractional shares support any dollar amount.
   Bot calculates exact quantity needed.

Q: Does fractional mean lower execution quality?
A: No. Robinhood's infrastructure handles fractional shares natively.
   Same fill quality as whole shares.

Q: What if I run bot 24/7?
A: Bot respects market hours (9:30–16:00 ET, Mon–Fri).
   Scans outside hours are skipped automatically.

Q: Can I sell fractional shares?
A: Yes. rh.order_sell_market(symbol, fractional_quantity) works.
